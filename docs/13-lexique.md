# 13 — Lexique

| Terme | Définition |
|---|---|
| **Antenne** | Phase de diffusion en direct du programme. |
| **Alerte info** | Séquence marquée comme information urgente. |
| **Candidat** | Dans un sondage, un débatteur proposé au vote. |
| **Chef d'édition** | Rôle responsable de la planification et des conducteurs d'émission. |
| **Chef de plateau** | Rôle chargé du déroulé technique du plateau. |
| **Conducteur** | Document de production du jour. Type `redaction` (rédaction) ou `emission` (plateau). |
| **Conducteur d'émission** | Conducteur de type `emission`, partagé entre chef d'édition et présentateur. |
| **Conducteur de rédaction** | Conducteur de type `redaction`, utilisé pour la réunion et les sujets. |
| **Conférence** | Réunion de rédaction enregistrée dans l'application. |
| **Débat** | Type d'émission/séquence opposant 2 à 4 débatteurs ; seul format avec sondage. |
| **Débatteur** | Rôle d'un intervenant dans une séquence DÉBAT (`debatteur`). |
| **Digital** | Publications vers les plateformes web et sociales. |
| **Espace métier** | Espace partagé (dossiers, tâches, commentaires, pièces jointes). |
| **Fiche intervenant** | Profil d'une personne invitée (identité, fonction, logistique, QR). |
| **Habilleur** | Rôle chargé de l'habillage (incrustations, graphiques) en antenne. |
| **Intervenant** | Personne participant à une séquence, interne ou externe. |
| **JRI** | Journaliste reporter d'images (`FonctionJournalisteEnum::JRI`). |
| **Journaliste** | Personnel interne, avec fiche dans `journalistes`. |
| **Journaliste responsable** | Journaliste affecté à une séquence (`journaliste_responsable_id`). |
| **Matricule** | Identifiant employé généré pour un journaliste. |
| **No-show** | Intervenant attendu mais absent. |
| **Parcours intervenant** | Suivi logistique d'un intervenant pour un conducteur/une émission. |
| **Ponctualité** | Marquage de l'arrivée d'un journaliste à la réunion. |
| **Présence** | Ligne `conducteur_presences` liant un journaliste à un conducteur de rédaction. |
| **Présentateur** | Rôle/ancre de l'émission ; vue dédiée du conducteur. |
| **QR code signé** | QR contenant un jeton (JWT ou opaque) permettant un accès public contrôlé. |
| **Réunion de rédaction** | Pointage + sujets qui alimentent le conducteur de rédaction. |
| **Remix IA** | Synthèse automatique d'une veille via un fournisseur IA. |
| **Séquence** | Bloc unitaire d'un conducteur (un sujet, un reportage, un débat…). |
| **Sondage** | Vote public en direct pendant une émission débat. |
| **Statut** | État courant d'une émission, d'un conducteur, d'une séquence ou d'un sondage. |
| **Veille** | Collecte et synthèse d'informations depuis des sources externes. |
| **Workflow** | Enchaînement des étapes terrain → montage → habillage → livraison → diffusion. |
| **Zone miroir / espace partagé** | Voir « Espace métier ». |
